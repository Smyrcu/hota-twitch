Streamer token

The token binds the plugin in your game to this channel. It is shown once; generating a new one replaces the old.

Interface scale

The HD Mod interface scale you play with; cards and hover areas follow it.

Setup

  1. 1. Generate the token above and copy it.
  2. 2. Paste it into hota-twitch.ini, next to hota-twitch.dll in your game folder.
  3. 3. Start Heroes III. This page will show “connected” once the game sends its first state.
